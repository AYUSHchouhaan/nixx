Overview

Three standalone smoke tests verify that the agent's supporting infrastructure actually works. Each is a single Bun script that connects to the real backend, performs a minimal end-to-end check, and exits non-zero on failure.

┌─────────────────────┐ ┌──────────────────────┐ │ test-sandbox.ts │─────▶│ Daytona API │ │ (sandbox-worker) │ │ create + echo run │ └─────────────────────┘ └──────────────────────┘ ┌─────────────────────┐ ┌──────────────────────┐ │ test-redis.ts │─────▶│ Redis (BullMQ) │ │ (contracts) │ │ ping + job roundtrip│ └─────────────────────┘ └──────────────────────┘ ┌─────────────────────┐ ┌──────────────────────┐ │ test-server.ts │─────▶│ LangGraph server │ │ (agent-brain) │ │ /ok + coding graph │ └─────────────────────┘ └──────────────────────┘

Each test follows the existing packages/db/scripts/test-db.ts pattern: a single main() that logs a clear pass/fail line and calls process.exit(0) or process.exit(1).

Redis / BullMQ

File: packages/contracts/scripts/test-redis.ts

bun run test:redis --filter=@repo/contracts

Behavior:

  • Connects using REDIS_HOST / REDIS_PORT (default localhost:6379).
  • Calls queue.waitUntilReady() with a 10-second deadline so a missing Redis fails fast instead of hanging.
  • Reads queue.redisVersion to confirm the connection is live.
  • Enqueues a smoke job and reads it back with queue.getJob(...) to prove write/read works.
  • Removes the job and obliterates the throwaway agent-to-sandbox-test queue.

Sandbox (Daytona)

File: apps/sandbox-worker/scripts/test-sandbox.ts

bun run test:sandbox --filter=sandbox-worker

Requires DAYTONA_API_KEY. Behavior:

  • Creates a sandbox named nixx-smoke-<timestamp> using the production DEFAULT_SANDBOX_CREATE_PARAMS.
  • Runs echo nixx-ok inside it and asserts the output matches.
  • Deletes the sandbox in a finally block so cleanup happens even on failure.

LangGraph Server

File: apps/agent-brain/scripts/test-server.ts (server must already be running).

bun run test:server --filter=agent-brain

Targets AGENT_BRAIN_URL (default http://localhost:4000). Behavior:

  • GETs /ok and asserts { ok: true }.
  • GETs /info and logs feature flags.
  • POSTs to /assistants/search with { graph_id: "coding" } and asserts the assistant exists.

Verification

All three scripts typecheck cleanly with tsc (exit 0). The Redis test was exercised against an environment without a running Redis instance and correctly failed fast:

❌ Redis/BullMQ connection test failed: Could not reach Redis at localhost:6379 within 10000ms — is it running?
The sandbox and server tests require their respective backends (Daytona API, LangGraph server) to be running to exercise the real paths.
