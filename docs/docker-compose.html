Nixx Docker Compose deployment

Nixx runs four services: web, Agent Brain, the Daytona sandbox worker, and Redis for BullMQ queues.

ServiceHost portPurpose
web3000Next.js UI and API routes
agent-brain4000LangGraph coding graph
sandbox-workernoneBullMQ worker for Daytona operations
redis6379Queue broker

Start

docker compose up --build -d
docker compose logs -f web agent-brain sandbox-worker

Open http://localhost:3000. Stop with docker compose down. Redis data is stored in the redis-data volume.

Build notes

  • The web image installs with Bun but runs next build on Node — Next.js 16's production build fails under Bun's CommonJS wrapper.
  • Bun installs workspace dependencies inside each app's own node_modules, not the repo root, so start commands must use workspace paths.
  • The Agent Brain image also copies pruned source, since the LangGraph CLI needs langgraph.json and src/graph.ts.

Configuration

  • Web: database, Better Auth, GitHub OAuth/App credentials, and BETTER_AUTH_URL=http://localhost:3000.
  • Agent Brain: DATABASE_URL and OPENAI_API_KEY.
  • Sandbox worker: DAYTONA_API_KEY, with optional Daytona URL and target.
  • Compose sets Redis to redis:6379 and Brain to http://agent-brain:4000. Do not use localhost between containers.

OAuth and CORS

Set the GitHub callback to http://localhost:3000/api/auth/callback/github. Normal browser traffic does not need CORS because the browser only calls web; web calls Agent Brain privately. If Brain is exposed directly later, allow only the exact frontend origin and avoid * with credentials.

Secrets

Keep environment files outside Git. Rotate any database, GitHub OAuth, GitHub App private-key, OpenAI, or Better Auth credentials that have appeared in shared output. The GitHub private key must remain valid PEM.
