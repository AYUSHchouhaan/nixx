Nixx API reference

The web app exposes a JSON API under /api plus an SSE endpoint for streaming agent output. Every endpoint except the Better Auth handler requires an authenticated session; unauthenticated requests return 401.

Authentication

Better Auth mounts its handler at /api/auth/[...all]. Sign in through GitHub OAuth at /login. Success writes two HttpOnly cookies: GITHUB_ACCESS_TOKEN_COOKIE and GITHUB_INSTALLATION_ID_COOKIE. API routes read them to mint short-lived installation tokens.

Threads

POST /api/threads

Creates a thread and its LangGraph thread.

FieldTypeRequiredDescription
sandboxIdstringnoDaytona sandbox id; defaults to the thread id
repoUrlstringnoRepository URL stored in metadata
branchstringnoBranch stored in metadata
titlestringnoDisplay title stored in metadata

Response: { "id": "..." }

GET /api/threads/[threadId]

Returns the thread plus its agent messages. Only the owning user can read it. Returns 404 for missing or foreign threads.

{ "thread": { "id": "...", "sandboxId": "...", "metadata": {}, "createdAt": "...", "updatedAt": "..." }, "messages": [] }

POST /api/threads/[threadId]/run

Starts an agent run and blocks until it finishes.

FieldTypeRequiredDescription
querystringyesTask description
repoUrlstringyesRepository to operate on
branchstringnoBase branch

Response: { "summary": "..." }

POST /api/threads/[threadId]/stream

Streams agent events as SSE. With a query it starts a new run; without one it reconnects to the active run. Emits values, messages, and messages-tuple events. Invalid bodies return 400.

POST /api/threads/[threadId]/run/cancel

Interrupts the running agent run. Response: { "ok": true }

GitHub

GET /api/github/repositories

Lists repositories accessible to the installation. Response: { "repositories": [...] }

GET /api/github/branches?owner=<owner>&repo=<repo>

Lists branches. Missing owner or repo returns 400. Response: { "branches": [...] }

GET /api/github/installation-token

Mints an installation token. Response: { "installationId": 0, "token": "...", "expiresAt": "..." }

Error shape

Errors are JSON with an error field. Common messages are Unauthorized, Thread not found, and GitHub installation ID missing.
